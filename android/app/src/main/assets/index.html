Download logs

Saves everything the bot has logged as one .zip file in Downloads/FXSignals.

  • logs/trades.csvEvery signal: pair, timeframe, strategy, entry / SL / TP, indicators at the signal, and the result.
  • logs/market_snapshot.csvEvery pair on every timeframe: price, RSI, EMAs, MACD, ATR, Bollinger Bands, the chosen strategy, and why there was or wasn't a signal. Updated hourly.
  • logs/scans/One line per scan (every 5 minutes) for the last 30 days: time, data problems, new signals, closed trades.
  • logs/last_scan.txtEverything the bot printed in its latest logged scan, including errors.
  • signals.json · sent_signals.json · backtest_reportThe signal history, the list of signals already sent, and the strategy report if you ran it.

Connect to your bot

The app reads signals.json from the GitHub repository where your bot runs.

GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Pick only this repository, and give Contents: Read-only. Leave empty if the repository is public.
